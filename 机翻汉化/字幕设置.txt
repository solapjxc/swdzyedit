# 死亡打字员 中文字幕 —— 可调设置（改完保存，重启 TodSubCN.exe 即生效，不用重新打包）
# 写法：键<Tab>值  或  键=值  都可以。行首加 # 表示注释（不生效）。
# 这个文件删掉也没关系 —— 程序内部的默认值就是下面这些（已经调好）。

# ⚠ 出问题时的调节方向：
#   字幕消失太快、来不及看    -> 调大 MIN_SHOW_S
#   字幕结束后赖着不走        -> 调小 STALL_HIDE_S
#   某句压根没显示出来        -> 调小 RESCAN_FAST_S，或调大 CONFIRM_MAX
#   冒出别的章节的台词        -> 调小 CONFIRM_MAX（更严格的活跃性确认）

# ===== 时序类 =====
# 出现后至少显示多少秒（低于这个时间一律不会被判结束，保证看得清）
MIN_SHOW_S	1.0

# 计时器停滞多少秒判定「这句已结束」。游戏每帧把计时器 -1，
# 一旦没人再减它，说明对象已注销、英文字幕已经消失
STALL_HIDE_S	2.0

# 轮询间隔（毫秒）。有些句子只存在两三百毫秒，采样要比它密。
# 机器吃不消（CPU 变高）可改回 25；想更保险就 10
POLL_MS	16

# 重新扫描字幕对象的间隔（秒）。有对象时慢慢扫(RESCAN_S)，
# 一只都没有时快扫(RESCAN_FAST_S) —— 新句子随来随接管
RESCAN_S	1.5
RESCAN_FAST_S	0.02

# 新对象先观察几次采样、确认「计时器真的在动」才显示。
# 内存残骸的计时器永远不动，靠它就显示不出来 = 防串台
CONFIRM_MAX	5

# 兜底：同一句停留超过这么多秒无论如何判结束
HIDE_S	10.0

# ===== 外观类 =====
# 字号 = 游戏窗口宽 / FONT_DIV（数字越大字越小）
FONT_DIV	30
# 字幕面板最宽/最窄占可用宽度的比例
PANEL_MAX_R	0.92
PANEL_MIN_R	0.24
# 文字左右留白（像素）
PANEL_PAD_X	34
# 字体名（想换黑体写 SimHei）
FONT_NAME	Microsoft YaHei
