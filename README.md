# 死亡打字员 · 单词编辑器

把《死亡打字员》(The Typing of the Dead, PC) 的单词改成任何你想要的内容。

原版游戏更适合学完打字之后的练习，而本工具支持自定义游戏单词，可以进行基本指法等不同阶段的打字练习，只需要替换相关字母即可。比如所有怪物头上的单词的都是“A”之类的。  

目前能替换99%的单词，剩下的一点请自行研究。  

感谢deepseek的工作，全部代码由大模型完成。甚至这个说明都是D指导写的。

##  EXE

需要NET Framework 4.x以上环境，一般win10以上自带，没有的话自己安装。

想改代码就改 `WordEditor.cs`，然后双击 `build.bat` 重新编译。编译完会自动跑一次自检。

## 怎么用

### 改几个词
1. 双击 EXE。它会自动找到游戏目录（找不到就点左上角「打开游戏目录」）。
2. 左边选一个文件，右边表格里 **「新词」那一列双击就能改**。
3. 改完点 **「保存」**。

> 第一次保存前，工具会**自动把整个 `word` 目录备份一份**，
> 放在游戏目录下的 `totd-word-editor-backups\` 里。

### 批量换词
点 **「批量工具」**，两个页签：

**查找替换** —— 把某个词或某段字符换成别的。可以选范围（当前文件 / 所有文件）、
限定组号、区分大小写、全词匹配、跳过问答题。

**用我的词库替换** —— 在文本框里每行填一个词，然后选一种方式：

| 同长度（推荐） | 游戏里每个词换成你词库里**同样长度**的一个词。同一个原词永远映射到同一个新词（按词内容哈希，可重复复现）。长度不变，所以排版不会乱。 |
| 按顺序循环 | 依次使用你词库里的词 |
| 随机打乱 | 用固定种子随机挑 |

两种都是**先点「预览」看结果，确认无误再点「应用」**。

### 导出 / 导入
- **导出为 TXT**：每个 `.bin` 导出成一个同名 `.txt`，一行一个词，顺序和游戏里一样。
- **从 TXT 导入**：把改好的 txt 写回游戏。会检查行数是否匹配、有没有非法字符。

### 备份与还原
- **「备份」**：手动备份一次。
- **「备份记录 / 还原」**：列出所有备份，随时还原。**还原前会自动再备份一次当前状态**，所以还原本身也能撤销。

### 校验
**「校验全部」**：把 488 个文件全部解码再重新编码，确认与原文件**逐字节一致**。
这是判断文件有没有被改坏的可靠办法。

## 命令行自检（可选）

```bat
死亡打字员单词编辑器.exe --selftest  E:\ttotd
死亡打字员单词编辑器.exe --savecheck E:\ttotd
```

- `--selftest`：488 个文件解码→编码，检查是否逐字节一致。结果写在 `selftest-result.txt`。
- `--savecheck`：在临时副本上完整走一遍「原样保存 / 改长 / 改短 / 拒绝中文 / 拒绝空词 /
  备份还原 / 校验」，不会碰真实游戏文件。结果写在 `savecheck-result.txt`。


## 游戏支持的字符

```
A-Z   a-z   0-9
空格  !  "  #  $  %  &  '  (  )  *  ,  -  .  /  :  ?  @
```

**别的字符存不进去**（中文、é、`~ [ ] _ ; < > = \ ^ | ` 等）。
输入了不支持的字符，工具会当场拒绝并告诉你哪个字符不行，文件不会被改动。

原版最长的词是 **40 个字符**，超过工具会提示，但允许保存（方便试错）。

## 文件格式

替换思路在FORMAT.md`，这里只列要点：

```
整个文件每字节 XOR 0x41
  ↓
目录表: N × 12 字节 (group_id, plain_offset, cipher_offset)
哨兵:   FF FF FF FF + 8 个 00
数据区: 明文 + 00 + FF 补齐到 4 字节；密文同理
       相同字符串只存一份；最后一条不补齐
  ↓
密文 = 明文逐字符过一张固定替换表（大写 +0x6B、小写 +0x65、数字 +0x72、标点固定）
```

因为目录表里存的是**绝对偏移**，改词导致数据区长度变化时重算偏移即可，
**所以词想改多长就改多长**，不需要保持长度一致。
